# OPENFUND

**A Unified Trading Experience**

Openfund is an independent trading platform combining a custom trading terminal, wallet connectivity, market visualization, and planned on-chain trading infrastructure.

## Technology Stack

HTML, CSS, JavaScript, React, RainbowKit, wagmi, viem, TanStack Query, and esbuild.

## Local Development

Clone the repository and install dependencies:

    git clone https://github.com/algomanlife/openfund.git
    cd openfund
    npm ci
    python3 -m http.server 4173

Website: http://localhost:4173/dist/

Trading Terminal: http://localhost:4173/dist/terminal.html
