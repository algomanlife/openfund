# 0034. Editorial and distribution authority

Status: proposed for review.

Interface strings retain versioned fallbacks. Directus may override the
published display text for a mapped key and locale. Existing editorial content
continues to use its owning collection. Financial records, position mutation
rules, certificate eligibility and executable downloads remain outside editor
control.

The Applications page reads reviewed artifacts from a versioned manifest. It
accepts installers only from the canonical repository's release assets. An
empty manifest shows unavailable desktop downloads while keeping the browser
workspace accessible.

Certificate records are derived from verified operational events and keep the
holder and amount recorded at issuance. The verification endpoint exposes the
public record only to callers with its random serial. Revocation preserves the
record and emits an audit event.
