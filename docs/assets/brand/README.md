# Documentation brand assets

`mark.svg`, `mark-mint.svg` and `mark-lime.svg` are byte-for-byte copies of the approved files in `brand/logos/`. Do not redraw, simplify or replace their geometry. The link/image validator checks exact fidelity.

Presentation graphics use current app colors: dark `#060808`, mint `#82e7bd`, lime `#C6FF52`, muted text and fine borders. English typography follows the app's Ubuntu direction with system sans-serif fallbacks. No new font binaries or invented brand origin story are introduced. Persian font/localization assets stay in their existing application locations.

The hero uses the existing English tagline **A clearer way forward**. Other graphic headings explain products and status; they are not a replacement identity. [Original brand inventory](../../../brand/README.md) · [Design system](../../design/DESIGN_SYSTEM.md)
