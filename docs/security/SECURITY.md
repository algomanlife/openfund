# Security and responsible development

- Never commit secrets, wallet seed phrases, private keys, credentials, user data or unredacted logs.
- Keep demo/testnet functionality clearly separated from production networks.
- Require explicit network checks and user confirmation for every signed transaction.
- Verify third-party dependency integrity, license and source authenticity.
- Review all public assets and **full Git history** before sharing sensitive or licensed content publicly.
- No audit or production security claim is made by this repository.
- Report security concerns privately to repository maintainers rather than publishing exploit details.
