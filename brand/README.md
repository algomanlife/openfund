# Openfund Brand System

## Existing source of truth

The original brandbook is preserved at `brand/brandbook/Openfund-brandbook.zip`. Existing design decisions and written content are in `DESIGN_AND_CONTENT_NOTES.md`. These materials should be reviewed together before revising brand language.

## Asset organization

- `logos/`: existing Openfund mark variants copied from `dist/assets/`.
- `typography/`: existing Openfund-named font files; distribution rights must be confirmed.
- `imagery/`: existing team imagery, subject to permission and privacy review.
- `brandbook/`: unchanged source brandbook archive.

Runtime assets in `dist/assets/` are intentionally retained to preserve working paths.

## Brand strategy workstream

Develop and approve the following from the actual brandbook and design notes: origin story and visual inspiration; mission; vision; values; positioning; voice and tone; logo construction and usage; colors and contrast; typography; illustration and photography direction; UI design tokens; accessibility; and application examples.

**Status:** Existing assets archived and organized. The narrative and detailed standards above are not represented as approved until reviewed against the source material.

## Asset rights

Third-party marks (including Gains, wallet providers, and infrastructure logos), licensed fonts, and imagery must not be presented as owned by Openfund. Confirm redistribution permissions before making this repository public.
