# Openfund brand assets

This directory groups existing brand artifacts **without changing the runtime asset paths in `dist/`**.

- `logos/`: approved Openfund logo variants.
- `typography/`: selected Openfund font assets if found; audit redistribution rights.
- `brandbook/`: source brandbook archive if found; preserve original materials.
- `imagery/`: selected project imagery if found.

## Brand documentation backlog

Extract and verify the brand origin story, inspirations, mission, vision, values, logo construction, visual system, palette, typography, iconography, imagery guidance, accessibility and usage examples from approved source materials. Do not invent source narratives or assume asset redistribution rights.

[Documentation presentation assets](../docs/assets/brand/README.md) preserve these logos exactly and use current application colors/typography.

The project is public; verify license and permissions before adding new commercial fonts or proprietary artwork.
