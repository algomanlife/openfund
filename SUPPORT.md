# Getting help

Openfund is an early-stage project maintained by a small team. Support is best
effort; there is no guaranteed response time.

| You want to… | Go to |
| --- | --- |
| Report a security vulnerability | **Privately**, through [SECURITY.md](SECURITY.md). Never in a public issue. |
| Report a bug | [Bug report](https://github.com/algomanlife/openfund/issues/new?template=bug_report.yml) |
| Report a layout, theme, RTL or accessibility problem | [UI problem](https://github.com/algomanlife/openfund/issues/new?template=ui_problem.yml) |
| Propose a feature or change | [Feature request](https://github.com/algomanlife/openfund/issues/new?template=feature_request.yml) |
| Fix or improve documentation | [Documentation issue](https://github.com/algomanlife/openfund/issues/new?template=documentation.yml) |
| Ask a question or discuss an idea | [GitHub Discussions](https://github.com/algomanlife/openfund/discussions) |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Before you ask

- Read the [README](README.md), the [documentation index](docs/README.md) and
  [Feature Status](docs/product/FEATURE_STATUS.md). Many features are simulated,
  read-only or planned; Feature Status says which.
- For local setup problems, see [Local development](docs/development/LOCAL_DEVELOPMENT.md)
  and [Testing](docs/development/TESTING.md).
- Search existing issues and discussions first.

## What we cannot help with here

- Account, wallet, purchase or payout questions about a specific person's
  account: never post wallet addresses, transaction details or personal data in
  a public issue.
- Investment, trading or financial advice.
- Recovering lost keys or seed phrases. Openfund never asks for them.
